Feature Highlights

日常分子克隆工作所需的核心能力

立即查看质粒图谱

导入序列文件后，快速查看环状或线性图谱，并在图谱、序列和注释之间联动定位。

带着上下文编辑序列

在同一工作区中编辑碱基、检查功能元件、管理注释，减少在多个软件之间切换。

检查限制酶与引物

显示限制性内切酶位点，辅助引物设计、片段定位和克隆方案检查。

查看 Sanger 测序结果

支持 AB1 文件查看，结合参考序列和图谱信息，更直观地检查测序结果。

Why GenePad?

Interface
