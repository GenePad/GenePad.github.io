文件格式开发文档

面向需要自行开发读取、转换或导入程序的开发者。这里把 GenePad 当前使用的 `.gen`、`.gjson`、SnapGene `.dna` 相关格式拆成独立页面，便于快速定位实现细节。

文件格式

序列文件定义

.gen 文件定义 SQLite 3 项目文件：12 张表定义、字段语义、坐标规则、分块与撤销机制。读完后能独立读写 .gen。 .gjson 文件定义 JSON 交换格式：顶层字段、各对象定义、与 .gen 的保真差异。读完后能解析 .gjson。 .dna 转换方案 SnapGene .dna 二进制包结构、flags 位、字段映射、0-based↔1-based 坐标转换。
