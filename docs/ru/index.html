01Рабочая область

Единая рабочая область для карт, последовательностей и анализа

Просмотр карт, редактирование последовательностей, поиск сайтов рестрикции и расчёт свойств белков объединены в одном интерфейсе; все представления синхронно следуют за выбранным объектом.

  • Переключение между кольцевым и линейным представлением в один клик; промоторы, CDS, точки начала репликации, сигналы poly(A) и другие элементы окрашены по категориям, подписи автоматически разводятся, не перекрывая друг друга, поэтому даже вектор с множеством элементов остаётся чётким и читаемым.

  • Выбор записи в таблице аннотаций позиционирует вид последовательности на соответствующий участок оснований с одновременным показом длины выделения, содержания GC и значения Tm; карта и последовательность связаны в обоих направлениях.

  • Сайты рестрикции размечаются прямо на двухцепочечной последовательности; при наведении видны распознаваемая последовательность, направление цепи и положения разрезов на обеих цепях; выступающие 5′-концы помечены явно — схему клонирования можно быстро проверить.

  • При выборе CDS в реальном времени рассчитываются молекулярная масса, изоэлектрическая точка, GRAVY, алифатический индекс и коэффициент экстинкции; для изоэлектрической точки встроено 19 алгоритмов для сверки, по умолчанию выводится результат алгоритма, рекомендуемого в литературе.

04Просмотр NGS-данных

06Инструменты

Богатый набор инструментов

Когда последовательность выделена, симуляция гель-электрофореза и дизайн sgRNA доступны прямо из контекстного меню; общая панель инструментов предоставляет ИИ-ассистента и библиотеку файлов; многоязычный интерфейс и поддержка «Open with» упрощают интеграцию с существующими рабочими процессами.

06-AКонтекстное меню

Context Menu

Симуляция электрофореза ДНК

C-01 · DNA GEL

Выделите последовательность и запустите симуляцию электрофореза из контекстного меню, чтобы заранее увидеть положение полос в агарозном геле; встроены распространённые маркеры молекулярной массы вроде Trans2K®, поэтому ожидаемый результат электрофореза можно оценить ещё до эксперимента.

Симуляция электрофореза белков

C-02 · PROTEIN GEL

Симуляция SDS-PAGE: выделите CDS или участок аминокислотной последовательности, чтобы «загрузить» образец; предокрашенные маркеры вроде PageRuler служат референсами молекулярной массы, положение полос рассчитывается в реальном времени.

Дизайн sgRNA для CRISPR

C-03 · CRISPR DESIGN

Двенадцать схем распознавания, включая SpCas9, xCas9, Cas12a/b и TnpB; настраиваются ориентация PAM, длина сид-области и фильтрация нецелевых совпадений — последовательности-кандидаты в один клик аннотируются на карте.

06-BГлобальные инструменты

Toolbox

ИИ-ассистент

T-01 · AI ASSISTANT

Напрямую читает и изменяет последовательность, аннотации и праймеры текущего файла; добавить элемент (feature), рассчитать Tm, транслировать белок, предсказать ORF — всё это делается командами на естественном языке.

Библиотека файлов

T-02 · FILE LIBRARY

Открытые векторные файлы индексируются автоматически, ИИ проставляет теги свойств пакетом, поддерживаются отслеживаемые папки; файлы находятся по свойствам плазмид — не нужно помнить имена файлов, возможен и поиск через ИИ-ассистента. Только индекс — исходные файлы никогда не изменяются.
