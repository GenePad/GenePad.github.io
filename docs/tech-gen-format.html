.gen Format

.gen 文件定义

`.gen` 是 GenePad / Gene Editor 的完整项目文件，文件本质是 SQLite 3 数据库。 它比 `.gjson` 更完整，适合保存工程状态、测序图谱、比对条目、撤销历史和附件。

Overview

读取原则

01

先按 SQLite 打开

无需自定义二进制 parser。用任意 SQLite 驱动打开 `.gen`，再按下方表结构查询。

02

序列按块拼接

`sequence_blocks` 需要按 `block_index` 升序拼接，不能依赖数据库默认返回顺序。

03

JSON 列延迟解析

`segments`、`qualifiers`、`components`、`alignment`、`references` 等字段是 JSON 字符串。

04

限制性酶切位点可重算

`.gen` 不需要持久化 `restrictionSites`，通常由读取程序根据主序列重新检测。

Schema

核心表结构

project_meta项目元信息 key-value 表
字段类型说明
keyTEXT PRIMARY KEY元信息键
valueTEXT元信息值，布尔值也以字符串保存

常见 key：name, description, isCircular, isDoubleStranded, accession, organism, date, moleculeType, division, version, keywords, source, comments, references, typeOfDisplay, customName, fileName。

sequence_blocks主序列分块
字段类型说明
block_indexINTEGER PRIMARY KEY0-based block index
basesTEXT NOT NULL该块碱基字符串，通常最多 10,000 bases
 
SELECT bases FROM sequence_blocks ORDER BY block_index;
