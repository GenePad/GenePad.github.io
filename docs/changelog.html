2026-09-03

v0.6.9

本次更新的两大主角是引物结合分析与分子克隆模拟：引物检测算法全面重写（动态规划对齐、热力学 Tm、简并与跨缺失引物支持），分子克隆改为按片段逐步处理并全新绘制组装示意图；同时 Linux 下的编辑与滚动性能大幅改进，序列比对视图与色谱交互更强，还带来了文件分享等新功能。

✨ 新功能

  • 引物结合分析（重写）：
    • 结合检测改为 3′ 端种子锚定 + 动态规划全局对齐：插入/凸环按幂律罚分，长插入不再被一刀切惩罚；位点按「退火碱基数优先、再比分数」排序
    • Tm 计算采用 SantaLucia 1998 结构式（十键最近邻热力学表、凸环熵罚、错配与简并碱基解析），独立引物与结合位点同一引擎
    • 简并引物支持：IUPAC 简并码参与对齐打分，NNK 等中段简并引物按「具体碱基锚定 + 简并凸环」三段结构直接产出
    • 桥式结合重建：引物跨模板缺失结合时按缺口对齐双臂，显示为三段结构
    • 结合参数全局化：删除 strict/standard/relaxed 三档模式，打分参数改在引物对话框内联面板即时调参、全局生效
    • 显示增强：相邻气泡碰撞自动合并、跨行引物行边界开口、跨行引物 5′ 端补显名称、位点 ◀▶ 导航按模板位置排序、酶表新增切点数列
  • 分子克隆模拟（重构）：
    • 与「构建质粒」解耦：默认 1 个片段按需添加，每片段一条多步处理链（限制性酶切 / PCR / 载体自连），每步显式生成中间产物，修改参数自动清掉受影响的后续产物
    • 酶切步骤选齐酶即自动酶切，产物区间即时高亮回标到原始序列（支持跨起点环绕）；酶选择列表跟随左侧图谱的酶池筛选
    • PCR 引物为单条寡核苷酸输入，自动按 3′ 端最长匹配拆分退火区与 5′ 延伸；引物成形后实时显示在图谱与序列视图
    • 取向多变体：两端接头相同的片段正反皆可连时自动枚举全部取向产物并按序列去重（载体取向固定），产物页胶囊选择器切换预览与导出
    • 组装示意图全面重画：载体开口骨架 + 插入片段按序填充、黏性末端接头画榫卯咬合、失败接头留空隙与凸起、线性分子两端画黏性末端凸出
    • 图谱/序列视图与打开质粒共用同一套代码；支持上下比例拉杆、全窗口铺满布局
  • 序列比对视图：
    • 比对区色谱图支持框选：选中一段色谱即映射回参考序列选区并锁定对应条目；色谱条目色球改为竖直高度拖杆，拖动即缩放峰幅值（1/3–3×，双击复位）
    • 色谱归一化改按峰高 P90 裁剪：常规峰接近满高，异常强峰只裁平顶部，不再压矮整段
    • 匹配碱基去掉浅绿背景、错配底色加深；地图上的比对标签锚定到比对起点（圆形图沿弧排布、下半圈保持正立）
    • 单行模式命中区间跳转钮改为视口中心粘滞：始终居中，仅被两侧命中块推开
    • 导入比对序列后自动跳转到第一个比对区：等全部计算完成自动定位，无需手动点击
  • 文件与系统集成：
    • 工具栏新增分享按钮：把已保存的文件直接交给系统分享面板（Windows / macOS / Android），双端 FASTQ 会把 R1/R2 一起分享
    • 设置新增「关于本程序」页（使用条款 + 隐私策略）；另存为菜单按「推荐 / 其它」分组重组
    • 匿名使用统计：安装标识 + 使用时长，每 7 天上报一次（设置中可关闭），官网新增实时数据页展示系统分布
    • AI 翻译语言文件改为分段翻译 + 分段自动重试 + 断点续传
    • FASTQ 视图左下角补设置按钮；图谱双击酶切位点直接打开限制酶信息框
  • FASTQ（NGS）：
    • 配对记忆迁移到应用数据目录：不同运行形态共用同一份记忆，条目按归一化路径命中，旧单向条目反向兜底，多选批量配对框按记忆预填
    • 序列分析报告「带裁切锚点」口径下锚点区段彩色标记：Top20 直方图与 Top100 表格中锚点碱基同色显示
    • 术语统一为「读段」；取消分析不再卡死

⚡ 性能与流畅度

  • Linux 性能大修：序列视图轴刻度改纯 CSS 绘制并裁剪常驻阴影；遗留同步后端命令全部改异步（大型比对不再冻结全部窗口）；冷启动分包；ORF 预测防抖收敛
  • 碱基编辑链路重写：以内存序列单次批量写库，1Mb 序列的写库调用从约 200 次降到 2 次；撤销/重做不再回读数据库；编辑历史仅保留最近 500 条，文件不再随编辑无限膨胀
  • 质粒库扫描改单事务批量写入，网络盘数千文件显著提速

🐛 问题修复与体验改进

  • 修复 Linux「打开方式」列表不显示 GenePad 与 .gen 文件被识别为世嘉 ROM 的问题
  • 修复分子克隆 / 电泳工具窗口跨窗口传参丢失
  • 修复图谱 Ctrl 两点配对选区不生效；图谱滚轮缩放时外层容器跟着滚动
  • 修复单行模式平滑跳转被逐帧取消的问题（滚动回显、轴线再居中、拖拽平移三处冲突源）
  • 右键菜单点空白处可靠关闭，二级子菜单纵向自动避让不再截断
  • FASTQ 配对询问框取消后不再残留窗口占位

2026-08-27

v0.6.8

本次更新的主角依然是 NGS（FASTQ）测序数据：多选批量打开与拖拽配对、fastp 式裁切、拼接过滤、可溯源导出一应俱全；AI 助手学会了直接操作 FASTQ 文件，另有一批易用性与性能改进。

✨ 新功能

  • 批量打开 + 拖拽配对：
    • 一次选中多个文件（打开对话框或欢迎页拖入均可）即可依次打开；包含 FASTQ 时会弹出配对窗口，把左右两栏文件拖到一起就组成 R1/R2，也能拖回退回单端、先建多对再逐对补齐
    • 不想手动拖？「一键自动匹配」会按首条 read ID 智能配对，配不上的保持单端
    • 确认前会逐对校验，配对不上的以红字提示留在行上
  • fastp 式读级裁切处理：
    • 新增固定区间裁切、质量滑窗、polyG / polyX 清除、超长截断，与 fastp 软件同类功能行为一致
    • 开启后浏览视图和导出结果都按处理后的序列显示，「显示原文」随时可对照原始数据
  • 拼接过滤：
    • 「仅保留成功拼接」滤掉没有重叠区域、只是首尾相接的双端 read
    • 重叠区错配过多的（大概率是假重叠）也会被排除；窗口未完整覆盖某一端的 read 整对剔除
  • 裁切方向自动识别：
    • 自动判断 read 方向：判定为反向的双端文件自动交换 R1/R2，单端整条反向互补后再裁切显示，不会再出现「切反一侧」
    • 提供镜像开关，一键还原原始方向
  • 导出可溯源：
    • 每条导出记录的头部都带处理痕迹标记（兼容 fastp 规则），下游分析管线可以直接解析它经过了哪些处理
    • 双端数据可以分别导出 R1/R2，也可以拼接成单条 _merged 文件；范围可选整个文件或已加载部分
  • AI 助手学会处理 FASTQ：
    • AI 可以直接打开 FASTQ 文档（自动识别并校验 R1/R2 配对），帮你查询信息、搜索序列、翻译阅读框、做裁切、生成序列分析报告（可随时取消），还能添加临时局部标注
  • 基因文件库：
    • 监视哪些文件类型现在可以自行勾选（默认勾选各序列格式；FASTQ 在清单中但默认不勾）
    • 重新打开库窗口时恢复上次的分类与路径；记录名称统一显示完整文件名，更好辨认
  • 其他：
    • 设置页新增「查看最近更新」，最新一期更新日志可以在应用内直接阅读
    • macOS / Linux 的「检查更新」改为打开官网下载页，不再直链当前平台用不了的安装包
    • 压缩的 FASTQ 文件（裸 .gz）增加兜底关联，在系统关联失效的电脑上也能右键用 GenePad 打开

⚡ 性能与流畅度

  • FASTQ 计数明显提速：双端 gz 快约 18%（实测每秒约 470 万条 reads），明文文件约快一倍
  • 长片段拖选时视图随光标自动横向滚动，不必反复松手翻页
  • 序列分析与全文件计数同时进行时自动互相让路，两个大扫描不再互相拖慢

🐛 问题修复与体验改进

  • 修复 Windows 下偶发的第二次启动无法弹出主窗口的问题
  • 配对记忆改为双向记录：无论以 R1 还是 R2 作为主文件重新打开，都能提示上次配对的另一端
  • 修复更新窗口 / 日志窗口关闭后残留透明空壳的问题
  • 多选打开后按单端处理的文件，不会再被反复询问单端 / 双端

2026-08-26

v0.6.7

本次更新最大的变化是新增了 FASTQ 测序数据的浏览与分析功能，同时限制酶库扩充到原来的 3 倍多，并加入了一键 BLAST 查询。

✨ 新功能

  • 全新：打开 FASTQ 测序文件：
    • 现在可以直接打开 .fastq / .fq 文件及其 .gz 压缩包，浏览测序数据
    • 自动识别单端 / 双端数据；双端文件的第二条序列按互补链配对显示，还能一键拼接出参考链
    • 打开文件即可看到 reads 总数、平均质量等统计；很大的文件不必等全部载入，随时可以继续加载后面的部分
    • 新增裁切：设置左右锚点挑出想要的 reads，一键导出为 .fastq.gz 压缩文件，中途可随时取消
    • 框选一段区域可以直接汇总导出 CSV，或生成一份「序列分析报告」（含数量统计与 Top20 直方图）
    • 浏览时支持六框翻译、随手添加临时标注、按 DNA 或蛋白质序列搜索
  • 选中序列即可 BLAST：
    • 选中一段序列（或一个 CDS 标注）后右键，即可提交 BLAST 在线查询：NCBI 会自动填好序列直接打开网页；国内网络可选 CNCB，自动复制序列并打开浏览器粘贴即可
  • 限制酶库大扩充：
    • 内置酶从 218 种增加到 765 种，覆盖 NEB 与 Thermo 全部目录，以前找不到的酶切位点现在都能标出来
    • 默认改用「NEB & Thermo」酶池，老用户会自动切换过去，无需手动设置
    • 图谱底部新增一行酶池与筛选开关，不用的时候可以收起来
    • 修复打开 GJSON / FASTA 文件后看不到酶切位点的问题
  • 插入 / 替换序列更顺手：
    • 插入片段时可以搜索带酶切位点的序列、直接以反向互补形式插入
    • 可以直接粘贴蛋白质序列（自动翻译成 DNA），还能做密码子优化后再插入
  • AI 助手：
    • 可以让 AI 反查某个质粒属于哪个项目分类，或列出某个分类下的全部文件
    • 基因文件库里「标签」列的 AI 批量刷新按钮增加了新手引导

🐛 问题修复与体验改进

  • FASTQ 裁切不再出现左右切反的情况；快速拖动浏览时也不会再闪出空白
  • 长序列快速滚动明显更流畅，4K 屏上高速滚动不再白屏
  • 修复 SnapGene 文件里分裂特征显示错乱的问题
  • 同一份文档不会再被两个 GenePad 窗口同时编辑而互相覆盖
  • 选中区域恰好和某个标注完全重合时按 Del，会询问你是只删掉标注，还是连序列一起删除
  • 不同类型的文件在电脑上有了各自专属的图标；双击关联文件用 GenePad 打开的兼容性更好
  • 应用内的更新检查改为每天自动进行一次，有新版本能更快知道

v0.6.4

本次发布包含自 v0.6.2 以来的 70 项提交，重点新增 CDS 阅读框延伸可视化、按文件记忆视图布局、基因文件库「文件管理」与项目分类，并带来 npm 与 Homebrew 两大全新分发渠道。

✨ 新功能

  • CDS 阅读框延伸（序列视图）：
    • CDS 标注末尾缺少终止密码子时，沿翻译方向以虚线延伸并续显氨基酸，直至终止密码子（*）
    • 延伸虚线标注所属阅读框，与实心 Feature 同色背景，悬停 / 选中特效一致
    • 延伸区氨基酸可连续选中，点击虚线同时选中实心 + 虚线范围
    • 双击虚线延伸区，确认后一键把 Feature 标注范围扩展到完整阅读框
    • 跨行密码子只在起始行显示一次，交界氨基酸按真实三碱基居中
  • 视图布局记忆：重新打开同一质粒文件时，恢复上次的 Map / 序列面板布局与序列视图滚动位置
  • 基因文件库：
    • 新增「文件管理」列：按项目分类（支持嵌套子项目）与原始路径两种树视图，点击文件夹筛选，表格行可拖拽到项目归类
    • 新增「未分类」虚拟项目，自动收纳未归属任何项目的文件
    • 监视文件夹后台自动扫描新增 / 移除文件；扫描改为增量，未变化文件不再重复解析
    • AI 项目工具：通过 MCP 按项目 id 或完整路径管理文件归类
  • 环形图谱：地图卡片底部新增横轴，拖拽两端手柄可调节外层标签椭圆环宽度（隐藏序列视图时显示）
  • AI 助手：
    • 对话支持随时停止生成，输出不再限制长度
    • AI 翻译支持停止 / 重新翻译
  • 编辑标注对话框：新增「显示氨基酸」勾选框；操作按钮固定底部；添加标注时自动生成初始名称
  • 其他：
    • ORF 预测按钮图标改为「ORF」文字标识
    • 属性视图拓扑结构拨杆改为两段式样式
    • 选中悬浮面板背景改为半透明

🐛 缺陷修复

  • 修复 .gen 格式保存崩溃与克隆模拟窗口无限循环
  • 修复序列视图滚动位置恢复失效（挂载时的 {0,0} 上报把已存位置清零）
  • 修复单行模式 CDS 虚线标签滚动时的跳动
  • 修复基因文件库文件管理器标签页与标签云筛选范围

📦 分发

  • 新增 npm 分发渠道：npm i -g @genepad/app
  • 新增 macOS Homebrew cask：brew install genepad/tap/genepad
