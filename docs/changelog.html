2026-08-26

v0.6.7

本次发布包含自 v0.6.6 以来的 150 项提交，核心是全新的 FASTQ 测序数据浏览与分析能力，同时带来 BLAST 一键查询、限制酶引擎全面升级（默认酶池扩至 NEB & Thermo 并集 765 种）与插入/替换对话框增强。

✨ 新功能

  • FASTQ 测序浏览（全新）：
    • 支持 .fastq / .fq / .gz 只读浏览，Rust 原生流式解析，大文件秒开；单端/双端自动询问并记忆配对，R2 以互补链配对显示，可一键拼接参考行
    • 打开即统计总 reads 数；长文件按需加载，「再加载 10%」增量续载、「加载全部」断点续传
    • 属性框分组展示总体 / R1 / R2 统计，平均质量附 Phred 分级悬停说明
    • 浏览视图六项升级：六框翻译、临时局部标注（双击编辑 / Del 删除）、cell 内搜索（DNA / 氨基酸双模式）、双光标选区、贯通光标、质量柱整体收放
    • 选区可一键设为阅读框起始片段生成 CDS 标注；顶部工具栏新增「交换 R1/R2」
    • 裁切：左右锚点筛选 + fastp 式多线程流水线导出（实测提速约 12.8 倍），支持随时取消、读级过滤、导出为 gzip 压缩的 .fastq.gz
    • 贯通选区汇总导出 CSV：Rust 多线程逐列六桶计数 + 共识序列 + +1 框氨基酸
    • 「序列分析报告」：唯一序列计数、质量报告、Top20 直方图，附双端文件路径与程序信息
  • BLAST 一键查询：
    • 选区 / CDS 右键菜单新增 BLAST 子菜单：NCBI 自动预填序列打开网页，CNCB 复制序列并唤起系统浏览器
  • 限制酶引擎升级：
    • 酶表改由 enriched 库生成，从 218 种扩至 765 种，补齐 CpoI 等 547 个此前检不出的酶
    • 新增「NEB & Thermo」并集酶池并设为新默认（旧配置自动迁移）；检测统一走 Rust 引擎
    • 图谱底部新增可收起的酶池 / 筛选方案筛选行，与酶切表表头实时同步
    • 修复打开 GJSON / FASTA 后酶切位点不显示的问题
  • 插入 / 替换对话框增强：
    • 按限制酶位点搜索插入、反向互补插入；DNA / 氨基酸双模式（切换自动翻译、严格过滤）；氨基酸模式密码子优化后插入 / 替换
  • MCP / AI：
    • MCP 新增 project.lookup 反查质粒项目归属、project.files 按分类取文件；基因文件库「标签」列 AI 批量刷新按钮增加新手引导气泡
    • 更新检测频率新增「每日」档并设为默认

🐛 缺陷修复

  • FASTQ 单锚裁切方向归一化，修复「左右颠倒 / 切反一侧」；反向 read 双端自动交换 R1/R2、单端整条反向互补后再裁切
  • FASTQ 快速滚动速度自适应 overscan，高速滚动不再留白
  • 序列视图 4K 快滚白屏治理：方向性 overscan + 行数据缓存 + text-run 化绘制
  • SnapGene 反向分裂特征排序修正，环形图连接弧取最短弧并计入碰撞避让
  • 打开文档加文件锁（Windows 拒写共享 / Unix flock），防止多实例同时写同一文档
  • 自动标注 note 按界面语言单语生成，悬停不显示与保存后丢失的问题修复
  • 三平台「打开方式」全类型兜底注册；关联文件图标按类型一型一图全平台适配
  • 选中范围与某标注完全一致时按 Del，改为弹窗选择仅删标注或连序列一起删除

完整变更：v0.6.6...v0.6.7

2026-08-21

v0.6.6

本次发布包含自 v0.6.5 以来的 22 项提交，重点消除启动白屏与空窗闪现、增强基因文件库交互（行右键菜单、窗口内 AI 设置），并换用全新多色描边图标，附一批 Linux / macOS 细节修复。

✨ 新功能

  • 启动与窗口体验：
    • 所有窗口改为隐藏创建、首帧绘制完成后再显示，彻底消除启动白屏与空窗闪现
    • 窗口显示前将背景预设为主题色，去掉显示到首帧之间的白底；移除启动页 logo
  • 基因文件库：
    • 表格新增行右键菜单：打开 / 打开所在目录 / 使用其它打开方式 / 移出文件库，右键同时选中该行
    • 设置入口改为窗口内「AI 设置」专用弹窗，内嵌与主设置窗相同的完整 AI 配置面板，不再跳回主窗口
  • 图标与安装包：
    • 应用图标换用 v2 多色描边设计，基因文件库图标换为「冷藏样品盒 + 离心管」造型，全平台产物重新生成，并修复旧图标在部分渲染器下的暗色晕影
    • Android 自适应图标改为底色背景层 + 螺旋前景层，圆形 / 圆角方等任意遮罩下满幅无裁切
    • Windows 安装器完成页新增「添加到开始菜单」勾选（默认全选）；修复「立即运行」勾选不生效；升级安装提示文案简化
  • AI：
    • 默认质粒标签提示词扩充免标注清单（T7 启动子 / 终止子、polyA），减少 AI 冗余标注

🐛 缺陷修复

  • 基因文件库窗口开着时，双击桌面图标现在会显示主窗口（此前只聚焦库窗口，无法回到欢迎页）
  • 每文件缓存与工具窗数据改为上限 100 条，不再无限增长；移除从不读取却写入完整序列 JSON 的缓存项
  • Linux：补齐 16–256px 全尺寸图标（修复 48–96px 放大发虚）；桌面入口显示中文名「基因文件库」；窗口阴影改为 1px 描边，显示更清爽；标题栏按钮改为圆形；deb/rpm 系统安装不再写用户级残留文件，卸载更干净
  • macOS：修复主窗口不显示的问题，应用图标恢复圆角

完整变更：v0.6.5...v0.6.6

2026-08-17

v0.6.5

本次发布包含自 v0.6.4 以来的 55 项提交，重点新增通用元件自动标注（内置 1591 条参考库，检测提速约 10 倍）、基因文件库桌面快捷方式，并全面换用矢量源生成的藏青螺旋新图标。

✨ 新功能

  • 通用元件自动标注（新增）：
    • 内置 1591 个常见质粒元件参考库（启动子 / 抗性 / 复制子 / CDS / 荧光蛋白 / 2A 肽 / CAR·抗体元件等 22 类），一键自动标注全序列或选中区段
    • 核酸 / 肽段 / 蛋白三级检索：blastn 容错比对、肽段级精确匹配（密码子优化后的短标签也能识别）、blastp 蛋白流水线
    • 严格度预设与蛋白级检索开关；命中结果勾选预览后批量入库，note 写入中英双语说明与相似度 / 覆盖率
    • 相似度低于 95% 的命中自动加「like sequence / like protein」后缀；多段元件按参考段边界切分为分段标注
    • 检测全程可取消并显示真实进度；整体提速约 10 倍，CDS 蛋白路径另提速 2.4–5 倍
    • MCP 新增 common_feature.* 工具；「添加标注」菜单升级为添加标注 / 自动标注全序列 / 自动标注选定序列三项
  • 基因文件库：
    • 新增独立桌面快捷方式，一键直达基因文件库（Windows .lnk / Linux 应用入口 / macOS 迷你启动器）
    • 右侧详情与标签云面板支持一键折叠，状态持久记忆；标题栏新增「设置」快捷入口
    • AI 未配置时常驻琥珀色提示条，一键直达配置页；AI 助手按钮自动拉起 MCP server
  • 图标体系：
    • 全面换用藏青螺旋新图标，全部由矢量母版生成，修复 Windows 任务栏图标模糊
    • 深色模式下应用内 logo 自动切换为亮蓝螺旋；macOS / Linux 关联文件接入专属文档图标
  • 其他：
    • AI 助手窗口改为单例，再次打开置顶已有窗口；AI 配置面板重排，操作更顺手
    • Windows 安装器：语言自动跟随系统、覆盖安装前确认、完成页整合快捷方式与「立即运行」

🐛 缺陷修复

  • 修复通用元件检测停止按钮无响应，以及关闭窗口后自动标注永久失效
  • 修复 AAV 类文件蛋白检测报错（带状行边界溢出）与小写 GenBank 序列导致检索全部失效
  • 扫描 .gen 文件不再在原目录留下 -shm / -wal 伴生文件
  • CDS 延伸段标签改为「XX阅读框延伸区」格式，语义更清晰

完整变更：v0.6.4...v0.6.5

2026-08-15

v0.6.4

本次发布包含自 v0.6.2 以来的 70 项提交，重点新增 CDS 阅读框延伸可视化、按文件记忆视图布局、基因文件库「文件管理」与项目分类，并带来 npm 与 Homebrew 两大全新分发渠道。

✨ 新功能

  • CDS 阅读框延伸（序列视图）：
    • CDS 标注末尾缺少终止密码子时，沿翻译方向以虚线延伸并续显氨基酸，直至终止密码子（*）
    • 延伸虚线标注所属阅读框，与实心 Feature 同色背景，悬停 / 选中特效一致
    • 延伸区氨基酸可连续选中，点击虚线同时选中实心 + 虚线范围
    • 双击虚线延伸区，确认后一键把 Feature 标注范围扩展到完整阅读框
    • 跨行密码子只在起始行显示一次，交界氨基酸按真实三碱基居中
  • 视图布局记忆：重新打开同一质粒文件时，恢复上次的 Map / 序列面板布局与序列视图滚动位置
  • 基因文件库：
    • 新增「文件管理」列：按项目分类（支持嵌套子项目）与原始路径两种树视图，点击文件夹筛选，表格行可拖拽到项目归类
    • 新增「未分类」虚拟项目，自动收纳未归属任何项目的文件
    • 监视文件夹后台自动扫描新增 / 移除文件；扫描改为增量，未变化文件不再重复解析
    • AI 项目工具：通过 MCP 按项目 id 或完整路径管理文件归类
  • 环形图谱：地图卡片底部新增横轴，拖拽两端手柄可调节外层标签椭圆环宽度（隐藏序列视图时显示）
  • AI 助手：
    • 对话支持随时停止生成，输出不再限制长度
    • AI 翻译支持停止 / 重新翻译
  • 编辑标注对话框：新增「显示氨基酸」勾选框；操作按钮固定底部；添加标注时自动生成初始名称
  • 其他：
    • ORF 预测按钮图标改为「ORF」文字标识
    • 属性视图拓扑结构拨杆改为两段式样式
    • 选中悬浮面板背景改为半透明

🐛 缺陷修复

  • 修复 .gen 格式保存崩溃与克隆模拟窗口无限循环
  • 修复序列视图滚动位置恢复失效（挂载时的 {0,0} 上报把已存位置清零）
  • 修复单行模式 CDS 虚线标签滚动时的跳动
  • 修复基因文件库文件管理器标签页与标签云筛选范围

📦 分发

  • 新增 npm 分发渠道：npm i -g @genepad/app
  • 新增 macOS Homebrew cask：brew install genepad/tap/genepad

完整变更：v0.6.2...v0.6.4

2026-08-12

v0.6.2

本次更新重点重构了质粒图谱（环形 / 线性）的标签布局与高亮联动，AI 助手新增持久记忆与「AI 翻译语言文件」，并完善基因文件库与 Windows 安装体验。

✨ 新功能

  • 质粒图谱（环形 / 线性）：
    • 标签布局全新重构：外环标签排布到最外层并自动避让，Feature 标签沿轨道弧形排列，图谱更清晰
    • Map / Sequence 标签高亮联动：悬停、Ctrl 多选，统一金色高亮，引物多结合位点同步指示
    • 新增引物显示开关，工具栏改为毛玻璃浮层，引物箭头与限制酶显示优化
  • AI 助手：
    • 新增持久记忆，AI 可记住你的使用偏好
    • 支持按界面语言生成回复与会话标题，可自定义标签提示词
    • 扫描文件夹后自动携带文件分布上下文，辅助标签生成
  • AI 翻译语言文件：
    • 新增「AI 翻译语言文件」功能：流式输出，实时显示思维过程与译文
    • 自定义语言导入支持跨窗口与重启记忆
  • 基因文件库：
    • 支持文件存在性检测与一键清理缺失项
    • 列表项支持双击打开
  • 打开方式：打开成功 / 失败后弹出结果提示（含错误详情），可一键关闭窗口
  • 安装体验：
    • Windows 安装器支持中英文切换、许可协议与覆盖安装
    • 全平台文件关联；Windows 右键菜单启动时自动注册
  • 其它：
    • 质粒库更名为「基因文件库」，标签云更名为「所有标签」
    • 文件名 / 路径悬停滚动显示

🐛 缺陷修复

  • 修复若干 bug（图谱渲染、AI 输出、安装程序等）

完整变更：v0.6.1...v0.6.2

2026-08-06

v0.6.1

✨ 新功能

  • 质粒库全面升级：
    • AI 自动标签生成：新增 tag 表、丰富 AI 上下文，并提供 plasmid.tags MCP 工具
    • 质粒库窗口单例、文件信息与标签编辑、扫描仅补缺标签
    • 多选批量操作、文件名修复、UI 改进与 MCP 提示词优化
    • MCP 自动开启、冷启动优化、标签芯片编辑器
  • 引物 Tm 值计算迁移至 Primer3：退火温度计算更准确
  • 引物标签渲染与交互优化：
    • 序列图谱上的引物标签显示优化
    • 环形图谱引物标签布局改进，防止标签重叠
    • Feature 与引物标签渲染优化，跨序列视图（环形/线性）的引物交互改进
  • 工具箱菜单分类：顶栏工具箱按功能分类展示
  • 顶栏快捷工具可配置 + 属性按钮激活态
  • 属性面板化 + AI 供应商扩展与思考开关
  • AI 聊天体验改进：思考/输出按时间顺序交错显示，复制按钮移至左下角，支持复用空白会话
  • MCP 新增 file.open 与 file.reveal 工具：AI 可打开文件并在文件管理器中显示
  • 主题切换左侧新增打开方式按钮

🐛 缺陷修复

  • 质粒库：保存后刷新质粒指纹并暴露标签生成状态
  • 质粒库：重开文件稳定触发标签回填与后台重生成，支持空标签重生成
  • AI：思考图标旋转修正，输出内容可选中并支持右键复制
  • 打开方式：外部打开前先关闭文件，并增加 isDirty 安全保护
  • Android：更新下载改为在浏览器中打开
  • 电泳模拟器：细化 ladder 控件交互

🔧 维护

  • 引物 Tm 计算引擎迁移（Primer3）与绑定诊断改进
